# TDDE09
Natural Language Processing
[Course Website](https://www.ida.liu.se/edu/ugrad/course.sv/TDDE09)

## What I Learned in This Course
- Tokenisation, subword methods, embeddings and text representation for NLP
- Building and analysing NLP models, from bag-of-words baselines to transformer-based models
- GPT architecture, including attention, masking, decoder blocks and text generation
- Using, evaluating, pretraining and fine-tuning language models in practice
- Efficient training methods and structured comparison of advanced models with simpler baselines
